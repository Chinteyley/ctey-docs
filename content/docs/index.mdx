## Explore My Work

Welcome to my project docs. I am Chintey Ley, a software developer specializing in TypeScript, React, React Native, and Python. I build full-stack web applications, cross-platform mobile apps, and machine learning tools.

[chintey.com](https://chintey.com) is the brand home. This site is where I keep write-ups, tech notes, and live links for the work.

## What You Will Find Here

The docs cover a few things:

- **Project documentation** -- Detailed write-ups for each project, including architecture decisions, features, and development process. Each project page explains what the project does, why I built it, and how it works under the hood.
- **Tech stacks** -- Breakdowns of the technologies used in each project. My stack typically includes Next.js, Angular, React Native with Expo, Flutter, PyTorch, and TensorFlow, among others.
- **Live demos and links** -- Where available, links to live deployments, app store listings, and source code repositories so you can try things out for yourself.
- **Contact information** -- Ways to reach me for collaboration, questions, or just to connect.

## Technologies

Across my projects, I work with a range of modern tools and frameworks. On the frontend, I primarily use React and Next.js for web applications and React Native with Expo for mobile. On the backend, I work with Node.js, Python, and various database systems. For machine learning projects, I use PyTorch and TensorFlow for model training and inference. I also have experience with Angular, Flutter, Swift for macOS, and cloud deployment platforms.
