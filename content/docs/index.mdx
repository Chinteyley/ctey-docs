## Explore My Work

Welcome to my project docs. I am Chintey Ley, a software engineer. I build full-stack web and mobile apps with Next.js, Expo, Angular, and Flask.

[chintey.com](https://chintey.com) is the brand home. This site is where I keep write-ups, tech notes, and live links for the work.

## What You Will Find Here

The docs cover a few things:

- **Project documentation** -- Write-ups for each project: what it is, why I built it, and how it works.
- **Tech notes** -- The stack behind each project. I usually reach for Next.js, Expo, Angular, or Flask, depending on the job.
- **Live demos and links** -- Live sites, store listings, and source when those exist.
- **Contact information** -- Ways to reach me.

## Technologies

Most days I work in TypeScript and React — Next.js on the web, React Native with Expo on phones. Backend is usually Node or Flask, with Postgres or Mongo. I also write Swift for small Mac apps, and I ship on Vercel and Cloudflare.
