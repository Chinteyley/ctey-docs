## Overview

Neko is a free, lightweight macOS menu bar application that places an animated pixel sprite kitten on your screen. The kitten follows your mouse cursor in real time, staying always on top of other windows — including fullscreen apps. It runs entirely from the menu bar with no Dock icon, making it an unobtrusive desktop companion. The latest release is v1.6.1. It supports macOS 12 or later on Apple silicon and Intel, and release builds are signed with Developer ID and notarized by Apple.

### Features

- Animated pixel sprite that tracks the cursor with smooth movement
- Always-on-top window, including over fullscreen apps
- Menu bar only — no Dock icon cluttering your workspace
- Three size presets: Small (16 px), Medium (24 px), Large (32 px)
- Three speed settings: Slow, Normal, Fast
- Hide Neko from the menu bar to park the kitten without quitting
- Launch at Login on macOS 13 and later
- Quit with `Cmd+Q`
- Settings persist between launches

### Tech Stack

- Swift
- SwiftUI
- Xcode
- AppKit

### How It Works

The app uses a timer-driven animation loop. The interval follows the selected speed: Slow (0.24 s), Normal (0.16 s), or Fast (0.10 s). A state machine picks the current sprite from the kitten's position relative to the mouse — idle, alert, thinking, grooming, yawning, sleeping, scratching, or walking in eight directions. The sprite sheet is a 5-by-6 grid of 16x16 frames, scaled with nearest-neighbor interpolation so the pixel art stays crisp at larger sizes.

### What I Learned

Building Neko deepened my understanding of macOS app development outside the typical window-based paradigm. Working with menu bar apps, always-on-top windows, and login items required diving into AppKit APIs that most SwiftUI tutorials don't cover. The animation state machine was a fun exercise in modeling behavior through discrete states and transitions.
