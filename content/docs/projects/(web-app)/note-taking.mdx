## Overview
A note-taking web application that allows users to manage and organize their personal notes. Features a clean UI for creating, editing, and deleting notes, with a live Markdown preview in the editor. The backend can generate a short title from note content through the OpenAI API. It was built as a full-stack project to explore Angular with an Express and MongoDB API, plus Docker and NGINX for deployment.

### AI Features

The Express API uses the OpenAI SDK (`gpt-4o-mini`) to turn note content into a short title or summary, including a dedicated "Generate Title" action in the editor. If the model call fails, the server falls back to a truncated excerpt. There is no streamed writing assistant, no expand-or-rewrite flow, and no folder or tag system in the current app.

### Key Features
- Create, edit, and delete notes
- Markdown editor with a live preview
- Optional AI-generated titles and short summaries via OpenAI
- Clean and intuitive UI with responsive design for desktop and mobile use
- User authentication with login and registration

### Tech Stack
- Angular
- MongoDB
- Express
- Node.js
- Docker
- NGINX
- OpenAI API

### Deployment

The application is containerized with Docker for consistent deployment across environments. The frontend Angular app and the backend Express API each run in their own containers, orchestrated with Docker Compose. An NGINX reverse proxy sits in front of both services, handling SSL termination, static asset caching, and routing requests to the correct container. This setup ensures the application runs reliably in production while keeping the development environment closely matched to the deployed configuration.
