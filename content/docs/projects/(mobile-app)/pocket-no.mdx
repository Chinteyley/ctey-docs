## Overview

Pocket No is an iOS app for saying no without the awkward pause. Open it, copy a line, and send it. There is a larger library if you want to browse, a favorites list for the keepers, and shortcuts so you can skip opening the app when you are in a hurry. On supported iPhones, Apple Intelligence can rewrite a line from what you type or say.

Android and web cover the basics. iOS gets the extra native bits: Home Screen Quick Actions and Siri Shortcuts.

### How It Works

1. Open the app, or jump in from a Home Screen Quick Action or Siri Shortcut.
2. Copy a fresh line. If the network is out, a smaller local set still works.
3. Browse or search the library when you want something more specific, and save favorites for later.
4. If the default line is too generic, Personalize takes typed or voice context on supported iPhones and uses Apple Intelligence to sharpen it.

### Key Features

- Instant copy, with a larger library behind it
- Favorites you can come back to
- Apple Intelligence personalization on supported iPhones
- Shortcuts and Home Screen Quick Actions on iOS

### Tech Stack

- Expo and React Native
- Expo Router
- Apple Intelligence on supported iPhones
