## Overview
Password Game (titled Secret Asor in the app) is a small Flutter teaching tool. It walks through four password-strength rules, in Khmer and English, so players practice building a stronger password one requirement at a time. The source is public. There is no live web demo or store listing.

### Game Design

The app is a four-level checklist, not the viral browser game with stacking absurd rules. Each level clears the input and asks for a new password that meets that level's rule: at least eight characters, then mixed case, then a number, then a longer password with a special character. Feedback is a simple strong/weak label plus a Verify button. Completing level 4 opens a short congratulations screen. Rule order is fixed, and there are no emoji, Roman-numeral, or math puzzles.

### Key Features
- Four progressive strength rules (length, mixed case, number, special character)
- Bilingual Khmer and English copy
- Real-time strong/weak feedback as you type
- Verify button to advance to the next level
- Flutter UI that can run on iOS, Android, and desktop

### Tech Stack
- Flutter
- Dart

### How to Play
1. Open the app and tap through the landing prompt.
2. Read the rule for the current level.
3. Type a password that meets that rule. The label turns green when it does.
4. Tap Verify to move on. The field clears for the next level.
5. Finish all four levels to reach the congratulations screen.
