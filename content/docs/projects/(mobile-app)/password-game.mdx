## Overview
Password Game is a small Flutter app. It walks you through a few password-strength rules, in Khmer and English, so you practice building a stronger password one step at a time.

### Game Design

Each level asks for a new password with one more requirement — length, mixed case, a number, then a special character. When it looks strong enough, you move on.

### Key Features
- Progressive password-strength rules
- Khmer and English copy
- Instant strong/weak feedback
- Runs on iOS and Android from one codebase

### Tech Stack
- Flutter
- Dart

### How to Play
1. Open the app and start the first level.
2. Type a password that meets the current rule.
3. Verify to move on.
4. Finish the last level for a short congratulations screen.
